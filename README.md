# Twitch Drops 자동 생성 툴

Eternal Return Twitch Drops 캠페인을 반복 생성하는 로컬 툴입니다. 이름/시작일/종료일만 다른 캠페인을 여러 개 자동으로 만들어줍니다.

- 각자 자기 PC에서 실행하고, 자기 Twitch 계정으로 로그인해서 씁니다.
- 로그인 정보는 본인 컴퓨터에만 저장되고, 다른 사람이나 서버로 전송되지 않습니다.

## 처음 설치할 때 (한 번만)

1. [Node.js](https://nodejs.org) 설치 (LTS 버전이면 됩니다)
2. 이 폴더(`twitch-drops-tool`)를 통째로 복사해서 본인 PC 아무 곳에나 붙여넣기
   - `automation-profile` 폴더는 다른 사람 로그인 정보가 들어있을 수 있으니, 복사할 때 **빼고** 가져가는 걸 권장합니다 (없어도 자동으로 새로 만들어집니다).
   - `node_modules` 폴더도 안 가져가도 됩니다 (아래 3번에서 새로 설치).
3. 이 폴더에서 터미널(PowerShell)을 열고 아래 명령어 실행:
   ```
   npm install
   ```
   설치가 끝날 때까지 몇 분 기다려주세요.

## 사용할 때마다

1. 이 폴더에서 터미널을 열고:
   ```
   npm start
   ```
2. 잠시 후 브라우저에 `http://localhost:5175` 페이지가 자동으로 열립니다.
3. **"연동 시작"** 버튼 클릭 → 새 크롬 창이 뜨면 본인 Twitch 계정으로 로그인
   - 이미 로그인되어 있던 적이 있다면 자동으로 "연동 완료"로 넘어갑니다.
4. 연동이 끝나면 아래 항목들이 활성화됩니다:
   - **고정 설정**: 게임, URL, 리워드 티어 구성, 생성 후 상태(TEST 권장)
   - **일자별 캠페인 목록**: 캠페인 이름 / 시작(UTC) / 종료(UTC) — "+ 행 추가"로 여러 날짜 한 번에 등록 가능
5. **"시작"** 버튼 클릭 → 자동으로 캠페인이 하나씩 생성됩니다. 진행 상황과 결과는 아래 로그/결과 표에 실시간으로 표시됩니다.
6. 다 끝나면 결과 표에서 "콘솔에서 열기" 링크로 실제 생성된 캠페인을 확인하고, Twitch 개발자 콘솔에서 최종 검토 후 수동으로 활성화(ACTIVE)하세요.

## 참고 사항

- 날짜는 반드시 UTC 기준, `2026-08-31T08:00:00Z` 형식으로 입력합니다.
- "생성 후 상태"는 기본값 **TEST**를 권장합니다. 바로 실제 방송에 노출되는 ACTIVE는 검토 후 신중하게 선택하세요.
- 리워드 ID는 쉼표(,)로 여러 개 입력할 수 있습니다.
- 서버를 끄고 싶으면 터미널 창에서 `Ctrl + C`.
- 다음에 또 쓸 때는 로그인 정보가 남아있어서(같은 PC라면) 보통 재로그인 없이 바로 "연동 완료"로 넘어갑니다.
- **CHZZK(치지직) 탭의 "쿠폰 상위 폴더 경로"** 설정 방법은 별도 문서를 참고하세요: [쿠폰-폴더-가이드.md](./쿠폰-폴더-가이드.md)

## 문제가 생기면

- 페이지가 "연동 준비 중..."에서 멈추고 안 넘어가면: 터미널 창에서 `Ctrl+C`로 서버를 끄고 `npm start`로 다시 켜보세요.
- 크롬 창이 이상하게 여러 개 뜨거나 꺼도 계속 뜬다면, 이 툴과 무관한 다른 프로그램(예: 다른 자동화 에이전트)일 수 있습니다.
- 그 외 오류가 나면 화면의 "진행 로그" 내용을 그대로 캡처해서 문의해주세요.
