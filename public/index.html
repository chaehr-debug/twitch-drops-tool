드롭스 자동 생성 툴 (로컬)

이 PC에서 실행되는 로컬 버전입니다. 로그인 정보는 이 컴퓨터에만 저장되며, "연동 시작"을 누르면 실제 크롬 창이 열립니다.

1. Twitch 계정 연동

버튼을 누르면 크롬 창이 새로 열립니다. 그 창에서 Twitch 로그인을 진행해주세요 (이미 로그인되어 있다면 자동으로 넘어갑니다).

2. 고정 설정

시청 시간(분)드롭 이름리워드 ID (쉼표로 여러 개 구분)

3. 일자별 캠페인 목록

캠페인 이름시작 (UTC, 예: 2026-08-31T08:00:00Z)종료 (UTC)

4. 실행

1. 치지직(네이버) 계정 연동

버튼을 누르면 크롬 창이 새로 열리고 네이버 파트너 로그인 페이지로 이동합니다. 로그인 후 "Naver Games" 선택까지 자동으로 진행됩니다.

2. 고정 설정

쿠폰 상위 폴더 안에서 날짜(MMDD)가 포함된 하위 폴더를 자동으로 찾고, 그 안의 "치지직_1.xlsx", "치지직_2.xlsx"... 파일을 리워드 순서대로 사용합니다.
사용 방법 템플릿의 {DEADLINE}에 들어갈 시각입니다. 날짜는 캠페인 종료일 다음 날로 자동 계산되고, 시각만 여기서 설정합니다.
리워드 이름 이미지 경로 사용 방법 (템플릿, {DEADLINE} 사용 가능) 리워드 ID 템플릿 ({MMDD} 사용 가능) 시청 시간

3. 일자별 캠페인 목록 (시간은 한국 표준시 KST 기준)

캠페인 제목 캠페인 ID 시작 (예: 2026-08-31 05:00) 종료 (예: 2026-09-01 05:00) 스트리머 UID (쉼표로 구분, 비워두면 전체)

4. 실행

SOOP 자동화는 아직 준비 중입니다.

1. 씨미(CIME) 계정 연동

버튼을 누르면 크롬 창이 새로 열리고 developers.ci.me/drops 페이지로 이동합니다. 씨미 전용 아이디/비밀번호로 직접 로그인해주세요 (자동 로그인 안 함). 한 번 로그인해두면 이 컴퓨터에서는 다음부터 자동으로 유지됩니다.

2. 고정 설정

애플리케이션/보상 그룹(쿠폰)/카테고리는 계정에 등록된 값으로 자동 선택되므로 따로 입력하지 않습니다.
쿠폰 상위 폴더 안에서 날짜(MMDD)가 포함된 하위 폴더를 자동으로 찾고, 그 안의 "씨미_1.csv", "씨미_2.csv"... 파일을 보상 순서대로 업로드합니다.
청구 마감 = 캠페인 종료일 + 위 일수, 위 시각으로 자동 계산됩니다. 각 보상의 만료 시간도 별도로 지정하지 않으면 이 값을 그대로 사용합니다.
보상 설명에 {DEADLINE}을 넣으면 위 "보상 청구 마감" 날짜/시각으로 자동 치환됩니다 (예: 9월 20일 05:00).
보상 제목 보상 설명 최소 시청(분) 보상 이미지 경로

3. 일자별 캠페인 목록 (시간은 한국 표준시 KST 기준)

캠페인 제목 시작 (예: 2026-08-31 05:00) 종료 (예: 2026-09-01 05:00)
